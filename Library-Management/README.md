# Library Management REST API
## Setup

1. Open this folder in VS Code.
2. Open the terminal in this folder.
3. Install dependencies:

```bash
npm install
```

4. Start the server:

```bash
npm start
```

For watch mode:

```bash
npm run dev
```

Server URL: `http://localhost:3000`

## API endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/books` | List all books |
| GET | `/api/books/:id` | Get a book by ID |
| POST | `/api/books` | Create a book |
| PUT | `/api/books/:id` | Replace a complete book |
| PATCH | `/api/books/:id` | Update selected fields |
| DELETE | `/api/books/:id` | Delete a book |
| GET | `/api/books/search?title=Node` | Search by title |
| GET | `/api/books/available` | List available books |

## POST and PUT JSON body

PUT requires all five fields. POST also requires all five fields. The `id` is generated by the application.

```json
{
  "title": "Express.js Fundamentals",
  "author": "Sara Khan",
  "category": "Web Development",
  "publishedYear": 2025,
  "available": true
}
```

## PATCH JSON body

PATCH accepts one or more fields:

```json
{
  "available": false
}
```

## Notes

- Data is stored in an in-memory array and resets when the server restarts.
- `.env` sets the port to `3000`.
- Do not commit `.env` or `node_modules` to Git.
- Test the endpoints using Postman or Thunder Client.
